# 数据采集中心 - 产品需求文档

## Overview
- **Summary**: 数据采集中心功能，提供A股股票数据的批量采集和本地存储功能，减少对外部API的依赖和调用频率，提升系统性能和稳定性。
- **Purpose**: 解决当前系统每次查询都需要调用外部API的问题，通过将A股股票数据采集并存储到本地数据库中，实现快速数据查询，降低外部API调用频率和网络延迟。
- **Target Users**: 金融数据分析师、投资者、开发者以及需要频繁使用A股数据的用户。

## Goals
- 实现A股股票基本信息（股票代码、名称、交易所等）的批量采集
- 实现A股股票实时行情数据的定期采集和更新
- 提供数据采集任务管理功能（启动、暂停、查看状态）
- 提供数据查询接口，优先从本地数据库读取数据
- 在菜单中增加"数据采集中心"入口
- 减少对外部金融数据接口的调用频率

## Non-Goals (Out of Scope)
- 不实现除A股以外的其他市场数据采集（港股、美股、期货等）
- 不实现复杂的数据分析和图表展示功能（这是现有页面的职责）
- 不实现数据可视化图表（复用现有可视化组件）
- 不实现用户权限管理系统
- 不实现数据备份和恢复功能

## Background & Context
- 当前AKShare Java项目是一个金融数据获取和可视化系统，通过调用东方财富、新浪等外部API获取数据
- 每次用户查询都需要实时调用外部API，存在网络延迟和API限流风险
- 系统目前没有持久化数据存储，所有数据都依赖外部API
- 项目使用Spring Boot 2.7.18作为后端框架，Vue.js 2.x作为前端框架
- 使用Maven进行项目管理，采用前后端分离架构

## Functional Requirements
- **FR-1**: 在前端导航菜单中新增"数据采集中心"菜单项
- **FR-2**: 提供数据采集任务管理界面，支持查看采集任务状态
- **FR-3**: 支持手动启动/暂停数据采集任务
- **FR-4**: 实现A股股票基本信息（代码、名称、交易所等）的批量采集
- **FR-5**: 实现A股股票实时行情数据的采集功能
- **FR-6**: 提供数据采集进度可视化展示
- **FR-7**: 提供采集日志查看功能
- **FR-8**: 实现数据查询接口，优先从本地数据库读取
- **FR-9**: 提供本地数据与外部API数据的切换选项
- **FR-10**: 支持手动清除本地数据库中的数据

## Non-Functional Requirements
- **NFR-1**: 数据采集任务应支持断点续传，避免重复采集已完成的数据
- **NFR-2**: 数据采集速度应控制在合理范围，避免对外部API造成过大压力
- **NFR-3**: 本地数据库查询响应时间应小于100ms
- **NFR-4**: 系统应具备错误处理和重试机制，确保采集任务的稳定性
- **NFR-5**: 数据采集任务应支持后台运行，不影响前端页面的正常使用

## Constraints
- **Technical**: 
  - 必须使用Java 8
  - 必须使用Spring Boot 2.7.18框架
  - 必须与现有AKShare Java代码库保持兼容
  - 数据库选型需要考虑轻量级、易集成的特点（推荐使用H2或SQLite）
- **Business**: 
  - 数据仅供学习和研究使用，不得用于商业用途
  - 需遵守外部API的使用条款和限流规则
- **Dependencies**: 
  - 依赖现有的AKShare Stock模块获取外部数据
  - 依赖现有的前端Vue.js组件库

## Assumptions
- 外部API（东方财富、新浪等）在数据采集期间保持可用
- 用户有足够的磁盘空间存储采集的数据
- 用户了解并同意遵守外部API的使用条款
- 数据库操作不会显著影响系统性能

## Acceptance Criteria

### AC-1: 菜单新增数据采集中心入口
- **Given**: 用户已登录系统并打开前端页面
- **When**: 用户查看顶部导航菜单
- **Then**: 应能看到"数据采集中心"菜单项
- **Verification**: `human-judgment`
- **Notes**: 菜单项应放在合适的位置，不破坏现有菜单结构

### AC-2: 数据采集任务管理界面
- **Given**: 用户点击"数据采集中心"菜单项
- **When**: 页面加载完成
- **Then**: 应显示数据采集任务管理界面，包含任务状态、操作按钮等
- **Verification**: `human-judgment`

### AC-3: 启动数据采集任务
- **Given**: 用户在数据采集中心页面，采集任务处于停止状态
- **When**: 用户点击"开始采集"按钮
- **Then**: 采集任务应开始执行，显示采集进度，状态变为"采集中"
- **Verification**: `programmatic`

### AC-4: 暂停数据采集任务
- **Given**: 采集任务正在执行中
- **When**: 用户点击"暂停采集"按钮
- **Then**: 采集任务应暂停执行，状态变为"已暂停"
- **Verification**: `programmatic`

### AC-5: 采集A股股票基本信息
- **Given**: 采集任务正在执行
- **When**: 采集任务完成股票基本信息采集
- **Then**: 本地数据库中应存储所有A股股票的基本信息（代码、名称、交易所等）
- **Verification**: `programmatic`

### AC-6: 采集A股股票实时行情
- **Given**: 采集任务正在执行，股票基本信息已采集完成
- **When**: 采集任务执行实时行情采集
- **Then**: 本地数据库中应存储A股股票的实时行情数据
- **Verification**: `programmatic`

### AC-7: 显示采集进度
- **Given**: 采集任务正在执行
- **When**: 用户查看采集任务页面
- **Then**: 应显示当前采集进度（已完成数量/总数、百分比等）
- **Verification**: `human-judgment`

### AC-8: 查看采集日志
- **Given**: 采集任务已执行过
- **When**: 用户点击"查看日志"按钮
- **Then**: 应显示采集任务的执行日志，包含时间、操作、结果等信息
- **Verification**: `human-judgment`

### AC-9: 从本地数据库查询数据
- **Given**: 本地数据库中已有采集的数据
- **When**: 用户通过其他页面查询股票数据
- **Then**: 系统应优先从本地数据库读取数据，而不是调用外部API
- **Verification**: `programmatic`

### AC-10: 清除本地数据
- **Given**: 本地数据库中已有采集的数据
- **When**: 用户点击"清除数据"按钮并确认
- **Then**: 本地数据库中的数据应被清除
- **Verification**: `programmatic`
