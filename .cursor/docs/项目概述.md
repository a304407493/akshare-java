# AKShare Java 项目概述

## 项目简介

AKShare Java 是 Python 版本 AKShare 的 Java 8 实现，提供访问中国金融市场数据的功能，包括股票、基金、期货、宏观经济指标和债券等数据。

## 新增功能

### 1. akshare-stock 模块增强

新增了 `StockInfoService` 服务类，提供以下功能：

- **股票名录查询** (`stockInfoACodeName`)：获取A股股票代码和名称列表
- **市场概况** (`stockSseSummary`, `stockSzseSummary`)：获取上交所和深交所市场概况
- **个股基础资料** (`stockIndividualInfoEm`)：获取个股的详细基础信息

### 2. akshare-web 可视化模块

新增了完整的 Web 可视化系统，包括：

**后端（Spring Boot）：**
- REST API 控制器
- CORS 跨域配置
- 通用响应封装

**前端（Vue + Element UI）：**
- 实时行情页面
- 历史K线图页面（使用 ECharts）
- 股票列表页面
- 市场概况页面

## 快速启动

### 后端启动

```bash
cd akshare-web
mvn clean install
mvn spring-boot:run
```

后端服务运行在 http://localhost:8080

### 前端启动

```bash
cd akshare-web/src/main/frontend
npm install
npm run dev
```

前端服务运行在 http://localhost:3000
