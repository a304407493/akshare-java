---

## 关于项目

**AKShare Java** 是 Python 版本 [AKShare](https://www.akshare.xyz/) 的 Java 实现，提供访问中国金融市场数据的功能，包括：

- 股票数据：实时行情、历史K线、分钟级数据、股票列表、市场概况
- 基金数据：开放式基金净值、ETF行情、基金名称列表
- 期货数据：商品期货行情、历史数据
- 宏观数据：GDP、CPI、PPI、PMI 等宏观经济指标
- 债券数据：可转债行情和信息
- Web可视化：基于 Vue + Spring Boot 的完整可视化系统

## 开发环境

- **Java**: 8 或更高版本
- **Maven**: 3.6 或更高版本
- **Node.js**: 12+（Web模块需要）
- **前端框架**: Vue 3 + Element Plus
- **后端框架**: Spring Boot
